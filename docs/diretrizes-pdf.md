# Pendências com o cliente: documentos PDF

Antes da Sprint 5, confirmar e registrar por escrito para Orçamento, Fatura e Ordem de Serviço:

- arquivo/modelo de referência de cada documento;
- logo, cores, tipografia e margens;
- textos fixos, cláusulas de garantia e observações;
- campos obrigatórios e ordem exata das informações;
- formato de valores, datas, numeração e status;
- dados de Pix que devem aparecer;
- local/campo de assinatura;
- regra de aprovação para alterações futuras de layout ou conteúdo.

Nenhum layout de PDF deve ser considerado aprovado sem retorno explícito do cliente.
